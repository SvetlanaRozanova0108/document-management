# Утилита генерации документов

## Общее описание

Утилита генерации документов предназначена для массового создания тестовых документов через API сервиса. Она читает параметры из файла конфигурации и создает указанное количество документов в статусе DRAFT.

## 🚀 Запуск утилиты

### 1. Подготовка к запуску

  Перед запуском утилиты убедитесь, что:

        Основной сервис запущен (доступен по адресу http://localhost:8080)

        База данных работает

        В проекте выполнена сборка

### 2. Файл конфигурации application.yml

  Описание параметров:

        count - Общее количество документов для создания = 1000

        api.url	- Адрес API сервиса	= http://localhost:8080/api/documents

        batch.size	- Размер пачки для отправки	= 100

        threads	- Количество параллельных потоков = 10

### 3. Запуск утилиты

  Для Linux/Mac:

        chmod +x run-generator.sh
        ./run-generator.sh

  Для Windows:

        run-generator.bat

## 📊 Мониторинг прогресса по логам

### 1. Логи в консоли

При запуске утилиты в консоль выводятся подробные логи:

Параметры генерации:
    Документов к созданию (N): 1000
    URL API: http://localhost:8080/api/documents
    Размер пачки: 100
    Количество потоков: 10

Пакетная обработка:
    Всего пачек: 10
    Размер пачки: 100

[ПАЧКА 1/10] Начало обработки в 2026-03-13 10:30:15.123
    Документов в пачке: 100

### 2. Прогресс по пачкам

Для каждой обработанной пачки выводится детальная информация:

[ПАЧКА 1/10] Завершена в 2026-03-13 10:30:17.456
    Результаты пачки:
    Успешно: 98
    Ошибок: 2
    Время выполнения: 2333 мс
    Общий прогресс:
    Обработано: 100 из 1000 (10.0%)
    Успешно всего: 98
    Ошибок всего: 2
    Осталось: 900

### 3. Финальный отчет

По завершении генерации выводится итоговая статистика:

Итоговая статистика:
    Запрошено документов (N): 1000
    Успешно создано: 998
    Ошибок: 2
    Всего обработано: 1000
Время выполнения:
    Начало: 2026-03-13 10:30:15.123
    Окончание: 2026-03-13 10:31:45.567
    Длительность: 90444 мс (90 сек)
    Средняя скорость: 11.05 док/сек

### 4. Логирование ошибок

При возникновении ошибок они детально логируются:

Ошибка создания документа: Счет №456-123
    Причина: Connection refused

Ошибка в пачке #3:
    Документ 301: Timeout
    Документ 305: 409 Conflict

### 5. Логи в файл

Логи также сохраняются в файл logs/generator.log:

Просмотр логов в реальном времени -
tail -f logs/generator.log

Поиск ошибок -
grep "ERROR" logs/generator.log

Подсчет успешных операций -
grep "Успешно создано" logs/generator.log
